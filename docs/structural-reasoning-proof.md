## Recommendation

Proceed with **one separate opt-in experimental family** built around compositional modules, localized context changes, and a shared physical repair. The finite construction below is a positive query-level PoC. It fixes the earlier “change first, then solve a single stationary world” operational shortcut because both contexts remain in the exact mission. It does **not** establish required mental revision, universal intervention necessity, three feedback rounds, or harder LLM performance.

The useful novelty is not more hidden coefficients: three independently selected primitive mechanisms are composed in a graph, two contexts share their graph and all but one mechanism, and the repair has shared upstream effects that must work in both contexts. A complete model may be anticipated from the start. That is legitimate reasoning, and no experiment order should be enforced.

## Exact construction

Everything below is public except the selected world. All arithmetic is in F3; every scalar is 0, 1, or 2.

Four primitive binary functions:

| Index | Function |
|---|---|
| 0 | `u + v` |
| 1 | `u - v` |
| 2 | `u * v` |
| 3 | `u*u + v` |

A world is `(topology, f, g, h, changed_module, replacement)`. Select each of `f,g,h` independently from the primitive grammar. The replacement is any of the other three primitives at the selected module. Context 0 uses the original triple; context 1 substitutes exactly that one module. The graph is shared and the other two mechanisms are unchanged. The graph alternatives are generated by these bounded parent choices:

| Topology | First module | Second module | Third module |
|---|---|---|---|
| 0, chain | `n1=f(x,y)+a` | `n2=g(n1,z)+b` | `n3=h(n2,x)` |
| 1, fork | `n1=f(x,y)+a` | `n2=g(y,z)+b` | `n3=h(n1,n2)` |
| 2, reconvergent | `n1=f(x,y)+a` | `n2=g(n1,z)+b` | `n3=h(n1,n2)` |

The observed response is `n3 + c + mode*d`. A physical repair is the shared actuator vector `(a,b,c,d)`, so there are **81 legal repairs**. The mission is to make all four responses zero using that same vector:

| Context | Input `(x,y,z)` |
|---|---|
| 0 | `(2,0,0)` |
| 0 | `(1,1,1)` |
| 1 | `(2,1,0)` |
| 1 | `(1,0,2)` |

This is an actual joint feasibility predicate, not equality with a private preferred answer. Admit **every** grammar world having at least one feasible repair, and disclose this solvability condition. There are `3 * 4^3 * 3 * 3 = 1,728` raw worlds and **615** admitted worlds. Select uniformly over the admitted world indices for the probability claims below. The public mission was chosen once during design from 120 candidate missions and then frozen; it is not selected using the episode's private truth.

The 615-world support retains all three topologies (241/194/180), all four primitives in every module, and all three change locations (194/205/216). No accepted context change is semantically inert over the complete query domain. There are 216 distinct winning-repair sets. Repair counts per world are: 300 worlds have 1; 25 have 2; 254 have 3; 36 have 9. Never replace these sets by a canonical answer when determining victory or information sufficiency.

## Complete query semantics and upper witness

A measurement may choose any context, any of 27 inputs, and any of 81 trim vectors, including mission inputs and repairs. No experiment order or mission-reading prohibition is needed. The raw domain therefore has **4,374** requests. Subtracting the publicly known `c+mode*d` from the one-trit response reduces this exactly to **486** normalized queries `(mode, x,y,z, a,b)`, with `c=d=0`. The normalization is a response-label bijection for each public request, not an information loss. There are 485 distinct outcome rows and 607 complete observational equivalence classes on the 615 worlds; retain original world masses when quotienting.

The independent script enumerates the entire normalized domain and all 81 decisions. It chooses a public query by a deterministic balanced-split heuristic, updates the public belief, and stops whenever **one repair wins for every remaining world**. It does not demand identification of the selected world. The exported policy wins in at most **7 queries**: 163 worlds use 5, 446 use 6, and 6 use 7. The policy has 806 belief nodes and was replayed against every admitted world in the independent model.

“Public policy” here means a witness using only public information. Keep its table, candidate counts, selected queries and repair recommendations in operator-side proof artifacts; none should become active-play hints. Evaluated players remain subject to the requested no-external-Python tool contract.

Artifacts:

- `scripts/poc_compositional_repair.py`: standalone standard-library enumerator; imports no NEXUS code.
- `joint-repair-probe-results.json`: complete numeric results and obstruction/fixture examples.
- `joint-repair-public-query-policy.json`: serialized query tree with public response branches and repair leaves.

Reproduce with `uv run python scripts/poc_compositional_repair.py`. The frozen-family analysis took approximately 16.25 seconds in this container; this is an offline proof experiment, not a generation benchmark. The query outcome table is only `486*615 = 298,890` bytes if packed. Runtime generation should decode one accepted world and check the cached certificate, not rerun the search.

## Complete-query shortcut results

These are **exact query-model success maxima under the uniform 615-world prior**, not physical-action or feedback-round results. “Guess” means selecting any one of the 81 repair vectors, with absorbing success and otherwise a binary rejection. Every query is allowed at every step. Known physical preparation is relaxed to be free.

| Policy class | Successful world mass | Probability |
|---|---:|---:|
| No queries, one repair | 41/615 | 6.67% |
| One query, one repair | 95/615 | 15.45% |
| Two adaptive queries, one repair | 202/615 | 32.85% |
| No queries, up to two repair guesses | 75/615 | 12.20% |
| One query followed by up to two guesses | 163/615 | 26.50% |
| Guess, then query after rejection, then guess | 130/615 | 21.14% |
| One query and up to two guesses, any order | 163/615 | 26.50% |

The two-guess calculation maximizes unions of winning sets, not target labels. One-query/two-guess arbitrary order is complete because its two substantive orderings are query-first and guess-first; any query after both guesses cannot add a win. At unlimited resources a fixed enumeration of all 81 repairs wins, if failed finishes are recoverable. For a no-measurement policy with at most `k` guesses, the simple valid ceiling is `min(1,41*k/615)`; exact overlap can make it lower. None of these bounds establishes the old strict three-round release gate.

## What is operationally unavoidable, and what is not

Even granting all **243** queries from just one context for free leaves no common winning repair in many posterior classes:

| Complete free evidence | Signature classes | Obstructed classes | Worlds in obstructed classes | Best one-guess success afterward |
|---|---:|---:|---:|---:|
| Context 0 only, all inputs and trims | 127 | 118 | 601/615 | 318/615 |
| Context 1 only, all inputs and trims | 130 | 113 | 582/615 | 327/615 |
| Both contexts, all inputs, only `a=b=0` | 589 | 6 | 12/615 | 609/615 |

Thus a “post-context first” policy is legal but cannot generally discard baseline behavior. For example, worlds `(0,3,2,0,1,0)` and `(0,3,3,0,1,0)` have identical complete context-1 responses: both replace module `g` by addition. Yet the former needs `a=2` and the latter `a=0` in every winning joint repair. Their repair sets are disjoint. Context-1-only data cannot resolve this regardless of the experiment count.

The all-untrimmed row is a **negative** result for a universal intervention requirement: 603 of 615 worlds lie in classes that admit a common repair after enough ordinary measurements. The family still supplies six exact counterexample classes where passive knowledge of both contexts is insufficient. One such pair is `(2,0,0,2,1,2)` versus `(2,0,2,3,2,2)`: every untrimmed observation agrees, but the only repairs are `(1,1,0,2)` and `(1,1,2,0)`. An internal trim experiment is needed for a guaranteed choice in that belief. These are useful targeted intervention fixtures, not grounds to claim every generated episode requires one.

Do not claim mandatory **mental** revision. A rational player may maintain the full conditional model from the beginning, select the changed context first, or infer both modes jointly. Prior observations retain their original context and never become false. The defensible claims are localized mechanism change, cross-context repair coupling, and observational/interventional obstructions in explicitly identified beliefs.

## Integration path and gates

The existing ontology seam is adequate: data-only role schemas; explicit catalog registration; graph interpreter; runtime `configure/transform/assess_mission`; public inference; terminal mission tracker; offline qualifier. No core action, replay, receipt, or session-family branch is required. `AppliedTreatmentTracker` already tracks a physically applied seal vector and permits overlapping success regions.

Use at most eight integer experiment settings `(mode,x,y,z,a,b,c,d)`, within existing configure arity/ranges, and four controller settings. Keep hidden node values and selected mechanisms out of public specimens. Store only public context/preparation settings and any measured scalar; immutable truth can reconstruct node values. Both contexts and every legal setting should be available from the start. A context may be a specimen-local modification; fresh or reusable samples preserve access to both contexts.

Allow a sensor measurement of a treated mission seal if desired: it must be the same one-context, one-input scalar already represented in the query table. Do not accidentally return the four mission residuals together, a hidden intermediate, or which mission test failed. A reader operation/probe and any preview must expose exactly the modeled observation. Actuator preview returns only public applied trims. Binary eligible finish rejection is informative and must update belief by excluding every world where that treatment would win. Ineligible finish is public-state feedback only and must not exclude a treatment.

A straightforward P1 witness can reuse one survey specimen: take seal and survey, move once; for each query configure/prepare/probe; configure/apply repair; finish. This is at most `2+1+3*7+3 = 27` actions before any recovery margin. A three-action rejected-repair allowance suggests 30 actions, **subject to real live replay and resource proof**. Do not choose a smaller proof-only budget. If a direct configure/probe path is legal, model its cheaper cost instead of adding preparation to manufacture difficulty. There is no claim that 30 actions defeats the current models.

Before registration:

1. Independently reimplement arithmetic and query/repair enumeration, including all 4,374 raw requests and their normalization. Match all 615 repair sets and public observation partitions.
2. Add a generic decision-mask audit or equivalent. `ObservationAudit` currently assumes a partition of unique target labels; neither its target count nor transitive target grouping is sound for these overlapping repair sets. The correct stopping test is `exists repair: belief subset winning_mask[repair]`.
3. Execute the serialized public witness through the real engine in every world; confirm physical doses, live finish/receipt, last-action ordering, replay, public/private validation, and no selected-truth access in the policy.
4. Prove the complete live public-response reduction, including rejected/free requests, previews, counters, stock reuse, invalid input classes and failed finishes. The current script is conditional on its query model; it does not certify the live interface.
5. Bind release claims to this exact public grammar, mission, support, weights, action/resources and observation projection. Cache offline proof data; measure cold and warm generation separately.
6. Preserve prior families and report this family as experimental. Use matched baselines: independent lookup, no local change, single-context mission, and the same complete-query greedy policy. A claim of harder model reasoning requires later evaluation; the current 5–7-reading witness is not a larger reading lower bound than dynamics.

Reject or downgrade any variant that admits a universal repair, whose selected change is observationally inert, whose inferred mechanisms do not affect mission acceptance, whose final-context-only data admits a guaranteed joint repair, whose supposed intervention claim fails the all-untrimmed closure, or whose complete live interface contains an unmodeled richer reading. Shared known arithmetic, graph depth, number of coefficients, and longer preparation scripts are not sufficient structural evidence.

Production integration uses seed modulo 615, not the exploratory Random sampler in the fixture table above. Use world indices from that table with the production generator; see structural-model-matrix.md.
