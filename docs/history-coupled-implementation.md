## Decisions / rejected premises

- Original h+=c*(k+1)^e, k+=c*(h+1)^e rejected: one orientation's goal unreachable
  in all 256 laws. Replaced with everywhere-nonzero shear increments.
- Acyclic output stage rejected as the primary experiment: visible properties could
  be completed independently after hidden properties. Tor/sen now cause disclosed
  delayed back-action; each update remains reversible.
- Physical shortest paths span 2–6, so no universal multi-stage lower bound claim.
- Anneal is ordinary, charged recovery for all profiles; no new-game/reset endpoint.
- Existing evidence-supported/compatible/failed distinctions retained. "Guaranteed
  repair" means a fresh preparation procedure here, with anneal recovery counted.
- Design and implementation review reports are committed alongside this ledger.
- Deep-tier admission failed: fixed panels, apparatus omission and repeated-finish
  shortcuts remain legal. Ship only as an explicitly experimental PoC.
