# Difficulty qualification and matrix admission

## Purpose and scope

The October 14 repair pilot won 42/42 missions. Its three-round construction is
valid, but a universal cancellation strategy makes the inference compact. Three
randomly selected truths also all used the cubic law. A successful reference
solver and distinct seeds therefore do not qualify a deep, diverse evaluation.

Implement an operator-only qualification layer and a reproducible matrix
preflight. Preserve existing ontologies, public evidence, axes, budgets, receipts
and default generation. Separate correctness, structural investigation demands,
coverage, and empirical model difficulty. No paid model calls or MindTrial edits.

## System design

1. Audit the **complete legal scientific measurement space**, not just reference
   experiments. Deduplicate identical observation partitions, retaining exact
   world/target alignment. Target-equivalent hypotheses need not be identified.
2. Report the prior's target classes, information-theoretic worst-case reading
   lower bound, best one-reading prediction success, and complete untreated-data
   ambiguity. These are information-model statements, not full-game optimality.
3. For selected truths, search all zero/one/two-reading certificates. A certificate
   is a set of actual outcomes that excludes every target-distinct admitted world.
   Even an oracle choosing experiments knowing the truth cannot beat a proved
   lower bound. This proves evidence requirements, not psychological complexity
   or immunity to lucky guesses/failed-finish information.
4. Explicitly identify the repair family's universal cancellation shortcut. Its
   three law branches are coverage controls, never promoted to a deep tier.
5. Choose causal candidates only when complete untreated data is insufficient
   for that truth and the stronger certificate gate passes. Inspect mission
   sensitivity, structure and simplifications; distinguish measured features
   from conjectures about LLM difficulty.
6. Validate matrix membership and coverage from generated episodes, not task
   labels. Separate scientific-world identity from transport pairing and reject
   unsupported cells, duplicate scientific cases, missing law/structure coverage,
   wrong declared roles, unproven thresholds and stale validation bindings.
7. Execute public-information policies, save/load and replay each selected cell.
   Bind reports to the exact matrix and source content. Artifacts containing seeds,
   hidden-law coverage or witnesses are operator-only and never enter evidence.
8. Full model rollout remains blocked until a small empirical pilot supports
   difficulty separation. Structural qualification cannot establish a failure rate.

The experiment model grants arbitrary fresh specimen preparation without charging
its physical action cost. This relaxation makes negative evidence-resolution
results stronger, but does not model finish feedback or prove feedback-round
depth. All queries remain serially available; no artificial scientific unlocks.

## Implementation phases and acceptance

### 1. Prove the gates

- Enumerate all legal causal sensor histories of length 0..2 and points, excluding
  only the existing six prohibited mission protocols; include all reference
  outputs. Check the enumeration independently against runtime semantics.
- Compute population/selected-truth shortcut metrics and compare the previous
  seed7 anchor. Determine attainable thresholds before selecting seeds.
- If current families cannot meet a proposed threshold, do not weaken or silently
  relabel it. Record the failed gate and qualify only the supported pilot role.

### 2. Implement admission and selection

- Add a small typed finite-observation audit module and ontology-specific
  operator adapters. Avoid changing or slowing normal generation.
- Add explicit matrix configuration, coverage constraints, deterministic selection
  and atomic progress reports. An error or incomplete audit must never say passed.
- Include runnable image preflight; operator files are not exposed through the
  player protocol. Document the exact commands and expected outputs.

### 3. Verify and review

- Test certificate logic against an independent brute-force oracle on small
  finite problems, including target equivalence and adversarial shortcuts.
- Regress the all-cubic matrix, duplicate seeds, insufficiently demanding cases,
  schema/type mistakes and incomplete/stale reports.
- Run selected live reference policies, replay, save/load, service privacy,
  existing compatibility tests and repository quality gates.
- Requalify the repair source binding after any package changes, retaining the
  existing proof and serialized witness. Never regenerate this during a build.
- Obtain an independent judgement of the implemented gates and their claims.

### 4. Deliver

- Publish changes on feat/theory-prior-axis with a roughly ten-cell matrix,
  machine-readable environment blocks, validation evidence and interpretation.
- Label difficulty as control / compact adaptive / structural transfer candidate;
  empirical difficulty remains uncalibrated. Explain what the next pilot tests.

## Decisions and invalidation triggers

- **Decision:** retain repair as a compact adaptive control. **Evidence:** all
  42 live traces follow its cancellation chain. **Invalidates if:** a new family
  changes that universally available strategy and is independently requalified.
- **Decision:** strengthen qualification before adding another ontology.
  **Reason:** test whether existing structural families support the requested
  distinctions; additional mechanics alone do not demonstrate difficulty.
  **Invalidates if:** complete shortcut audits cannot support meaningful tiers.
- **Decision:** preserve numeric T/D settings for compatibility; measured
  qualification bands are separate, explicitly scoped operator metadata.
- **Decision:** use existing uv/pytest/Ruff/Pyright conventions. Toolchain
  migration and deployment timing optimization are outside this task.
