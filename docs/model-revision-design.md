# Model revision and extension framework: system design

Status: implementation in progress, 2026-10-22. Base: `bf86ce8c` on
`feat/theory-prior-axis`. This document supersedes the post-pilot waiting gate.

## Purpose and evidence

The stateful pilot had 38 supported live victories, three final-answer failures
and two provider interruptions. Known update equations allowed staged inference,
neutral-input strategies and recoverable cycles. Additional actions did not
establish additional reasoning difficulty. Keep the family as a control.

The next opt-in family tests reconstruction of a composed mechanism from primitive
rules, and selective revision of an inherited model. The inherited model is
explicitly provisional: it explains the supplied archive, but is not privileged
truth. The player may ignore it and discover a correct model directly. There is
no forced belief, experiment order, verbal explanation or theatrical unlock.

Research informs this choice rather than guaranteeing its difficulty:

- NewtonBench v3 (https://arxiv.org/abs/2510.07172) motivates interactive discovery
  beyond static fits; its model/tool/noise conditions differ from NEXUS.
- Structural identifiability (https://arxiv.org/abs/2101.06382) distinguishes
  parameter identity from sufficient prediction. Equivalent constructions win.
- PyPA plugin guidance
  (https://packaging.python.org/en/latest/guides/creating-and-discovering-plugins/)
  supports explicit installed entry points for trusted operator extensions.

## Candidate mechanism and proof gate

Prototype a conservative packet network: bounded nonnegative inventories,
directed transfers of min(source inventory, 1 + destination parity), and two apparatus modes formed by
ordered compositions. The public primitive laws, inventory and construction
bounds are complete; derived apparatus equations and connectivity are hidden.
An inherited network matches short archived experiments. Longer mixed-mode
histories distinguish structurally different explanations. A built cartridge
must match observable behavior for **all finite histories**, including histories
beyond the laboratory limit. Global inventory conservation and earlier valid
predictions must be preserved. No noise, floating point or external Python.

Before integration, independently enumerate the candidate grammar and check:

1. Primitive conformance, deterministic execution and exact conservation.
2. Full-history behavioral equivalence, not just equality on a short test set.
3. Archive ambiguity, a genuine counterexample to each selected provisional
   model, and repair validity on both old and new observations.
4. Actual-outcome certificate minima, adaptive/fixed-panel upper bounds and
   zero/one/two-query shortcuts, including failed-finish feedback where claimed.
5. Single-mode closure, longer histories, synchronization and conditional
   decomposition. State precisely which shortcuts remain available.
6. Matched controls and distinct structural/behavioral coverage for selected seeds.

If the candidate collapses to a trivial reconstruction, change the candidate or
retain it only as a labeled shallow control. No silent relaxation of admission,
no failed search presented as proof, and no model-failure percentage promise.
An all-history mission does not by itself establish deep cognitive difficulty.

## Architecture and compatibility

Keep new physics, grammar, public evidence, posterior and qualification in a new
ontology adapter. Core still owns transactional actions, resources, canonical
state, replay, lifecycle and receipt authentication. Previous family identifiers,
seed mappings, contracts and default selection remain unchanged.

Consolidate repeated ontology registration into one descriptor that identifies
data schemas, runtime, generation and qualification. Imports remain lazy and
code-owned. Expose a narrow, documented author API and an executable example.
Automatic installed-package discovery is deliberately deferred: its source must first
participate in qualification provenance. The explicit trusted catalog is the supported
extension point; episode files never select Python paths or install packages. Reject conflicts,
unsupported contract versions and incomplete registrations clearly. Keep
qualification provenance explicit: registration is not difficulty admission.

Extract reusable finite-machine or observation-table components only where the
new family and an existing family demonstrate the same semantic requirement.
Prefer bounded immutable transition/observation caches and bitset posteriors;
measure cold and warm costs. Avoid a generic simulator framework or dependency
migration for this feature.

## Diagnostic fixes

Emit a bounded compact operator summary last, after detailed terminal history,
so an 8192-byte captured stderr tail retains the outcome and key counts. Preserve
the existing detailed event format; no active player response gains hints.
Split non-informative observations into committed instrument readings and previews;
do not label necessary physical control as wasted work. Preserve legacy metric
fields and explicitly document their semantics.

Game completion, evidence support, receipt validation and provider completion are
distinct. NEXUS cannot diagnose a raw provider response it never receives. Keep
the strict receipt validator and document the extra MindTrial capture needed;
do not modify public MindTrial or run paid model reruns in this task.

## Controls and non-goals

Keep P/R moderate and matched (P0, R1=64 where the public policy fits). Include
known-model execution, primitives-only discovery, provisional-model revision,
shallow negative controls and mechanism contrasts. T labels retain theory
sufficiency; D claims require explicit proof scope. No automatic new deep tier.

No main merge, old-family removal, noisy fitting, arbitrary code execution,
source access for players, artificial mandatory experiments or production claim
from an uncalibrated PoC.

## Proof outcome and rejected simplifications

The first one-packet candidate produced only 195 observable behaviors and a
largest archive group of 37. Adding a gate alone reduced observable diversity
further (153). The adopted destination-parity transfer, with a positive initial
inventory, yields 20,736 permitted wirings and **748 exact behavioral classes**.
The state has 56 legal inventories; no approximations or floating point are used.

Independent scalar code checks 2,322,432 transitions and conservation, all 20,736
wirings against their representative by unbounded product traversal, and 381,480
reader outputs. Distinct legal reader rows separate every behavioral class;
therefore the eight-mode laboratory limit suffices to identify behavior even
though acceptance checks all finite histories. This is an identifiability proof,
not a truncated acceptance test.

All archive groups have a constructive public policy using at most seven readings
(18 actions). The four selected hard behaviors need a reading-only certificate of at least four observations even
on their most favorable truthful outcome branch. Rejected submissions can replace
readings: selected worlds permit three readings plus one/two failed builds, at
13/16 actions. They cannot undercut the 12-action supported minimum. Complete single-mode studies
still leave 39, 39, 42 and 77 compatible behaviors respectively. The provisional
counterexample itself leaves at least three further readings necessary. Four
selected mechanisms differ after removing hidden-reservoir renaming and mode swaps.

The exact certificate search solves an actual-outcome set cover with dominance
reduction and a checked search cap. A capped search blocks admission. Its action
minimum is 2*C plus take, installation and finish, plus assembler configuration
unless the default construction is already correct. A rejected eligible build
eliminates one behavioral class; a legal reading distinguishing that class from
the actual world costs no more than a distinct rejected build attempt. Repeated
finishes of an unchanged build add no information. Thus binary finish feedback
cannot undercut the reported supported-action minimum. The certificate is replayed
through live public actions at exactly that cost. It is **not** the cost of a
worst-case guaranteed adaptive strategy; the reference bound is reported separately.

Unrestricted derivation, private mental strategies and universal cognitive
non-decomposability are not proved. Conservation is enforced by every primitive,
so this family tests using a conserving construction language, not discovering a
conservation law. The prior remains bounded. Good general algorithms may still
solve it easily. Empirical calibration requires the pilot.
