## What is now available

**Evidence auditing.** Revision submissions retain their pre-submission support
classification and now have a separate optional private witness report. A
contradicted construction receives an earlier reading/archive conflict or an
eligible rejected-finish witness. A compatible construction receives one surviving
alternative and a legal distinguishing experiment. Winning feedback never turns a
compatible submission into a supported one. The first available supported decision
includes its turn and canonical state hash. It is a historical point, not a promise
that support survives arbitrary future state changes.

The existing terminal performance schema remains intact. Extended operator
snapshots and the bounded stderr summary carry the additions; active player
responses do not. Public evidence/investigation hashes and assistance-call counts
are recorded. Provider completion and final receipt parsing remain observations of
the external harness, with an explicit runtime ledger for those fields. Null means
unobserved, not successful or failed. Keep the full log as well as the final tail:
a bounded summary cannot retain every concrete witness.

**Explicit interventions.** The default finish policy remains recoverable. The
single-shot condition terminates at the first eligible wrong construction; an
ineligible finish does not test a construction. The policy is disclosed in the
manifest and evidence. It changes the consequences of commitment, not the hidden
law or intrinsic certificate.

The optional `check` operation returns a boolean for consistency with the archive
and previously observed reader outputs. It returns no alternative, repair, hidden
truth or new measurement. It intentionally ignores finish feedback. Thus a
previously rejected but reading-consistent construction can still return true.
The check consumes a harness call and zero world actions, is logged, and is only
available while that explicitly assisted episode remains active. It is supported
through the session API and HTTP/client path used by the evaluation bundle; the
legacy action-only JSONL interface is not extended with this assistance operation.

**Qualified screen.** The preflight checks the independent scalar semantics,
certificate lower bounds and witnesses, public-policy wins, replay, action budget,
paired disclosures, and intervention equivalence. It computes C(L), short-history
closures, observable-state counts, topology keys, and discriminator availability.
Fixed-panel and short-word-first paths supplement the existing greedy public
identify-then-build policy. Their path costs are constructive bounds, not minima.

Source changes, incomplete reports and incompatible harness templates block export.
The complete harness template is pinned by hash in source. Exported service inputs
are constructed from the qualified cycle; altering family, axes, budgets, tool
permissions, prompts or provider settings in the source template requires a new
source-bound qualification. Credentials are supplied locally after export and
should not be archived with the result bundle. Archive a redacted final config and
its identity if local harness configuration is changed.

## W4: selective revision followed by control

The bounded proof of concept uses known old program 5866, a disclosed old history,
and a disclosed possibility of zero or one changed directed link. That is 45
possible new programs, stationary after the change. The player reconstructs the
current physical state from the old law/history. Experiments use a read-only clone
of that current carrier; a control word would then act on the actual carrier.
There is no hidden change to the public stationarity contract.

For the concrete history `[0,1]`, the current state is `(3,1,0,1)`. All 255 control
words of lengths zero through seven and 126 observation words through length six
were enumerated and compared with the independent scalar implementation.

The stronger full-history reachability check also examines **every one of the ten
physical states reachable under the known old program**, and every one of the 45
new programs. At each current state, no different exact-state target is reachable
under every permitted new law. The one focused redesign replaces exact-state goals
with a different displayed value; it also has no target reachable under all laws.
This is a physical solvability obstruction even when the new law is supplied.
More observations or a larger action budget cannot solve those impossible worlds.

Supplying the current state removes deterministic reconstruction; supplying the
new law removes discovery; supplying both leaves physical reachability. All these
controls preserve the obstruction. This prototype is therefore **not admitted**.
There is no model-capability conclusion and no general impossibility claim about
selective revision. A future attempt would need a deliberately different public
change class, goal, or control/repair vocabulary. This cycle does not keep enlarging
the design to rescue it.

## NW2: two-module cascade

The concrete cascade uses known reference programs 5866 and 6464. At most one
module changes, with at most one link changed: **89 joint worlds**. The interface is
fully specified: advance upstream, map its new display with `[0,1,0]`, then advance
downstream once. Both begin at `(2,1,1,1)` and reset for each experiment. The basic
observation is the final downstream display for words of lengths one through six.

The bounded repair vocabulary has three decisions: do nothing, restore the known
upstream module, or restore the known downstream module. Acceptance is exact
full-history downstream equivalence to the healthy cascade, from the disclosed
initialization. It does not require the original hidden wiring.

The downstream-only condition fails the information gate. A full-history
indistinguishable class contains **35 worlds** with no common successful repair:
some require upstream restoration, others downstream restoration. This is stronger
than a six-step observation-horizon limitation. Unlimited ordinary downstream
experiments do not separate those worlds before the chosen repair. A protocol
allowing tentative repairs, remeasurement and rollback would be a different
sequential intervention design and is not ruled out by this result.

Explicit upstream taps and downstream clamps restore a public winning policy:

| Observation condition | Constructive greedy worst-case readings | Scope |
|---|---:|---|
| Downstream only | No guaranteed pre-repair decision | All-history indistinguishability obstruction |
| Isolated tap/clamp control | 6 | Public policy; not an optimal bound |
| Downstream plus tap/clamp assistance | 4 | Public policy; not an optimal bound |

All worlds have a one- or two-reading optimistic decision certificate when local
access is allowed (87 have one; two have two). That does not prove a two-reading
adaptive guarantee. The six/four figures are reference-policy bounds.

Qualification uses 3 acceptance masks and 378 query rows, totaling 33,642 table
cells, within the existing 256-mask and 16-million-cell limits. The largest
reachable joint machine has 59 states. Exact joint correlations matter: for query
`[0]` with downstream output 0, 74 actual joint worlds remain, while multiplying
their separate module projections would invent 1,394 combinations.

The assisted version is a viable bounded composition **specification and positive
control**, not a demonstrated harder challenge or a production-ready environment.
It still needs playable action/cost semantics, live replay conformance and a matched
isolated-versus-combined model study before promotion.
