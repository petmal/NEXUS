## Experimental families and history

The repository keeps past designs, matrices, proofs, reviews and results for
replication. Dated reports describe their original source and run settings; they
are not automatically updated when the software changes. A historical experiment
is not a recommendation to rerun every row. Current source-bound preflight files
are maintained separately from archived results.

- T/D foundations: [scientific design](scientific-investigation-design.md),
  [T/D experiment synthesis](td-experiments-and-next-directions.md).
- Planning and resources: [planning](planning-resource-guide.md),
  [coordination](coordination-guide.md), [interference](interference-guide.md),
  [structural comparison](interference-comparison-guide.md).
- Model screens: [cross-axis](cross-axis-guide.md),
  [capability smoke](capability-smoke-guide.md), [fresh worlds](fresh-world-guide.md).
- Legacy controls: [difficulty semantics](difficulty.md),
  [qualification results](difficulty-qualification-results.md).

Mechanically qualified means the documented checks passed. Experimental,
qualified and empirically calibrated are different labels; consult each family's
scope before using its scores in a comparison.
